# Mini Quiz Battle

A 2-player Java Swing quiz game by Team Byte Battlers.

## Features
- 2 players, turn-by-turn
- 15 second timer per question
- +10 points for each correct answer
- Winner popup and Top 5 leaderboard

## How to run
1. Download QuizBattle.jar
2. Run: java -jar QuizBattle.jar
